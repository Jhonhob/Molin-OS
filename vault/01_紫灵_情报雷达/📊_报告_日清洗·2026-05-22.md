## 三、隐藏规律挖掘

### 规律一：规模效应——高产日成本效率高 40%

```
任务量  平均 CPT   平均 QA   样本
─────────────────────────────────
≥6 篇    ¥0.535     83.0     3 天
≤3 篇    ¥0.749     80.0     3 天
─────────────────────────────────
差异     -40%       +3.7%
```

**核心发现**：单任务成本与产出量呈强负相关。高产日（6-7 篇）CPT 仅 ¥0.52-0.56，低产日（2-3 篇）CPT 窜至 ¥0.57-1.12。原因推断：低产日有固定 token 开销（上下文加载、系统提示等）无法摊薄。

**业务含义**：每天至少产出 5+ 篇才经济。低于 4 篇时边际成本急剧上升。

### 规律二：逆直觉——高产日质量也更高

| 产出水平 | 平均 QA | Pass80 率 |
|---------|--------:|----------:|
| 高产 (6-7篇) | 83.0 | 67.3% |
| 低产 (2-3篇) | 80.0 | 44.3% |

高产日不仅更便宜，质量也更高。可能是"创作动量"效应——连续创作时质量系统化，零星创作时上下文重建消耗注意力。

### 规律三：周末效应不是简单的"产出减半"

| 维度 | 工作日(二-五) | 周末(六日) | 降幅 |
|------|------------:|----------:|-----:|
| 任务数 | 6.0 | 2.5 | -58% |
| API 成本 | ¥3.35 | ¥2.25 | **-33%** |
| CPT | ¥0.563 | ¥0.847 | **+50%** |

周末任务数减半，但成本只降 1/3——因为固定开销仍在。这导致周末 CPT 反升 50%。周末适合做低成本任务（短内容），不适合长文/复杂内容。

### 规律四：Pass80 率是最灵敏的"金丝雀"

```
Pass80率标准差 = 11.82%（所有指标中最高）
任务数标准差 = 1.79  → CV = 37%
Pass80率 CV = 21%    → 但绝对值波动范围大（33%-71%）
```

Pass80 率从 71%（高产日）到 33%（异常日），是最快反映系统健康度的指标。当 Pass80 跌至 40% 以下，通常伴随 CPT 尖峰或 Escalation。

### 规律五：平台覆盖的"收缩-扩张"脉冲

```
5/12: ▓▓▓ (3) → 5/13: ▓▓▓▓ (4) → 5/14: ▓▓▓▓ (4) → 5/15: ▓▓▓ (3)
→ 5/16: ▓▓ (2) → 5/17: ▓▓ (2) → 5/18: ▓ (1)
```

平台覆盖呈 2-3 天的脉冲衰减。高峰期后如果没有新的多平台排期输入，会自然收缩至 1-2 平台。需关注：**连续 3 天 ≤2 平台即为收缩信号**，当前已触发。
