墨麟OS运行于macOS/Python 3.11+/Node.js 24+环境，通过Molin-OS仓库一键部署，核心依赖DeepSeek API+Supermemory记忆服务，五个Agent通过Hermes profiles独立运行。

---

## 系统要求

macOS 14.0+(推荐15.0+)，Python 3.10+(推荐3.11+)，Node.js 22+(推荐24+)，Git 2.0+(推荐2.40+)，内存8GB+(推荐16GB+)，磁盘20GB+(推荐50GB+)。

## 环境变量

| 变量 | 必填 | 说明 | 获取方式 |
|------|------|------|---------|
| DEEPSEEK_API_KEY | 是 | LLM API密钥 | platform.deepseek.com |
| SUPERMEMORY_API_KEY | 是 | 长期记忆服务 | supermemory.ai |
| GITHUB_TOKEN | 是 | GitHub API访问 | github.com/settings/tokens |
| BROWSERBASE_API_KEY | 否 | 浏览器自动化 | browserbase.com |
| EXA_API_KEY | 否 | AI搜索 | exa.ai |

## 一键部署

git clone → cp env/.env.example .env → 编辑.env填入API keys → bash scripts/deploy.sh → make start。

## 目录映射

agents/name/ → ~/.hermes/profiles/name/，skills/ → ~/.hermes/skills/，molib/ → ~/Molin-OS/。

## 日常维护

make status查看状态，make health健康检查，make sync手动同步记忆，make backup手动备份到GitHub，make restart重启全部服务。
