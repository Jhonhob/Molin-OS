## 新创建的代码（agentic-stack）

```
molib/agentic_stack/
├── __init__.py          # 模块入口
├── memory.py            # 四层记忆系统 (working/episodic/semantic/personal)
├── skill_manifest.py    # 渐进式技能披露 (manifest + trigger loading)
├── lesson_lifecycle.py  # 教训生命周期 (candidate→graduate→reject)
└── data_layer.py        # 本地监控面板 (dashboard.html + daily-report.md)
```

### 四层记忆系统 (memory.py)
- MemoryEntry: 单条记忆（id, content, layer, significance）
- MemoryLayers: 四层容器，支持 add/query/archive_working/summarize
- 自动持久化到 ~/.hermes/agentic_memory/{layer}.jsonl
- working 层 2天自动归档到 episodic

### 渐进式技能披露 (skill_manifest.py)
- ManifestEntry: name, description, triggers(关键词列表)
- SkillManifest: load/save/find_matching(按任务描述匹配)
- 匹配后返回 top-3 按 priority 排序的技能

### 教训生命周期 (lesson_lifecycle.py)
- Lesson: id, content, status(candidate→staged→graduated→rejected)
- LessonLifecycle: candidate/stage/graduate/reject/reopen
- render_as_markdown() → LESSONS.md 格式

### Data Layer (data_layer.py)
- DashboardMetrics: sessions/tokens/cost/cron/skills/lessons
- DataLayer: record_session/export_html/export_report
- 输出 dashboard.html + daily-report.md
