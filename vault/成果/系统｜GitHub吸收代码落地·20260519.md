## 1. xhs_ai_publisher → molib/content/xiaohongshu.py

从 BetaStreetOmnis/xhs_ai_publisher (1.96K⭐) 提取核心模块，重写小红书内容引擎。

### 新增模块

| 类/模块 | 行数 | 功能 |
|---------|------|------|
| XHSSessionManager | ~80 | 登录态复用管理器 (storage_state + Chrome Profile scan) |
| XHSLLMAdapter | ~90 | AI适配器 (OpenAI/DeepSeek/DashScope/Ollama 兼容) |
| XHSCoverTemplate | ~60 | 封面/内容图片模板系统 (4种模板) |
| XHSScheduler | ~60 | 定时发布任务调度器 |
| XHSHotTrendCollector | ~50 | 热榜数据采集 (微博/百度/头条/B站) |
| XHSPublishEngine | ~70 | Playwright RPA 自动化发布引擎 |
| XiaohongshuEngine (统一) | ~40 | 整合所有模块的统一引擎 |
| CLI入口 | ~60 | xhs / xhs-publish / xhs-hot / xhs-status |

### 设计模式落地

1. **登录态复用** (Session Reuse) — `XHSSessionManager`
   - Playwright storage_state 持久化 + Chrome Profile 自动扫描
   - "一次登录，到处发布"
   
2. **AI适配器** (LLM Adapter) — `XHSLLMAdapter`
   - `LLMConfig.from_provider()` 工厂方法
   - `OPENAI_COMPATIBLE_PROVIDERS` 注册表
   - 无 API key 时 fallback 到内置模板生成

3. **Playwright RPA** — `XHSPublishEngine`
   - 发布操作指令输出 (需要浏览器环境执行)
   - 内置 login() 交互式登录引导

`molib/content/xiaohongshu.py` — 从 161 行扩展到 780+ 行 (v1.0 → v2.0)

## 2. Agentic Stack → molib/memory/retriever.py

将 agentic-stack 的 MemoryLayers 四层记忆系统集成到统一检索入口。

### 新增功能

| 功能 | 代码 |
|------|------|
| Agentic Stack 检测 | try/import，兼容无模块场景 |
| MemoryLayers 检索 | `_query_agentic_memory()` 按层/关键词评分 |
| Lessons 检索 | `_query_agentic_memory()` 含已毕业教训查询 |
| LLM 摘要生成 | `_call_llm_summarize()` 用 DeepSeek/OpenAI 生成摘要 |
| 数据源标注 | `retrieve_context()` 返回 `sources` 字段 |

### 集成架构

```
retrieve_context()
├── search_obsidian() — Obsidian 结构化知识
│   └── rank_results() + deduplicate()
├── _query_agentic_memory() — MemoryLayers 四层记忆
│   ├── working/     (当前任务状态)
│   ├── episodic/    (历史运行记录)
│   ├── semantic/    (长期模式/教训)
│   └── personal/    (用户偏好)
│   └── lessons.jsonl (已毕业教训)
├── 合并 + 去重 + 排序
├── 区块过滤 (section_filter)
├── LLM 摘要生成 (可选)
└── 返回统一格式
```

`molib/memory/retriever.py` — 从 146 行扩展到 280+ 行 (v1.0 → v2.0)
