# Molin OS · Obsidian Vault

Obsidian knowledge base mirror for Molin OS.

All content organized by type (8 flat directories). Synced from local iCloud Obsidian vault via vault_git_sync.py.

## Directory Structure

- 决策/ — Architecture decisions, strategic choices
- 知识/ — Research, domain knowledge, learning notes
- 流程/ — SOP, system integration, pipeline docs
- 成果/ — Weekly reports, milestones
- 报告/ — KPI dashboards, periodic reports
- 配置/ — System config metadata
- 产出/ — All agent execution outputs
- 学习档案/ — GitHub deep reading, paper notes
