二、可直接借鉴的设计模式
================================================================================

1. IRT 2PL/3PL实时自适应（lextures）：题目接受度区间的实时调整，学员答对→出更难同知识点题，答错→出更简答同知识点题。 → 墨麟逻辑思维课每章节末尾出5题IRT自适应测试，精确评估掌握度

2. Exploration对话式学习（oppia）：预设tutor对话分支树+学员选择驱动路径，非线性的"边做边学"。 → 墨麟每节逻辑课尾部署1个5分钟Exploration，用对话代替知识点总结，加深理解深度

3. Markdown-as-Cards（essentialist）：卡片=Markdown文件，标题=问题，内容=答案，FSRS自动调度复习。 → 墨麟学员每节课自动导出Markdown复习卡，嵌入课后复习SRS流程

4. 全功能Block Editor（learnhouse）：Notion-like编辑器用于课程内容创作，支持代码块、AI生成、实时协作。 → 墨麟课程创作后台可复用此模式，教师像写文档一样建课

5. AlloFlow五重输出（AlloFlow）：同一输入→分级阅读+测验+视觉组织图+教案+游戏化RPG。 → 墨麟逻辑题可自动生成：基础层(单选)→标准层(多选)→挑战层(开放推理)

五、与墨麟业务的具体结合点
================================================================================

1. IRT自适应出题 → 逻辑思维课每章节结尾第6-10题为IRT动态难度梯度，前三题热身后进入自适应段，精确评估当前掌握度

5. 一键分层输出 → 课程管理后台增加"一键分层"按钮，AI将当前课程自动生成基础/标准/挑战三版本，对应不同认知阶段的学员
