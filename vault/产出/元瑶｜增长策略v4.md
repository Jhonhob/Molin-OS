引擎C：教练Agent → LTV放大器

家长感知到"每节课都有进步" → 续费意愿增强 →

预期效果：续费率提升5-10个百分点

三个引擎叠加效应：转介绍↑ × 完课↑ × LTV↑ = 增长飞轮加速至少50%

B路线升级转化流程：
第1节试听 → 课后课次报告 + 诊断Agent生成"首次思维能力基线" → 家长收到第一份"孩子的逻辑能力X光片"
第2节试听 → 课后练习批改 + 诊断Agent跟踪某1个薄弱点的变化 → "孩子的XX思维比昨天进步了"
第3节试听 → 诊断Agent产出3节课综合评估：20种思维方法初步雷达图 + 成长趋势预测 → 家长看到的不是推销，而是"这3节课孩子收获了这些"

   分类思维掌握度78%（同龄平均水平约65%）

如果您继续学习，诊断Agent会每周跟踪这20个维度，
您看到的不是分数，而是思维能力实实在在的增长。"

6.6 AI Agent三层干预体系（新增：替代原6.3纯人力干预体系）

原方案的三层干预依赖辅导老师人力：
Level 1 自动化：AI推送同类题
Level 2 人工：辅导老师1对1沟通
Level 3 管理层：教研介入

B路线升级方案：AI Agent嵌入三层干预

Level 1 — AI诊断+教练自动干预（新增）
触发条件：单次作业正确率<60% / 诊断Agent检测到薄弱点下降
动作：诊断Agent自动标注薄弱点 → 教练Agent自动推送3道针对性练习 + 苏格拉底式追问陪练
响应时间：实时（原方案需等待辅导老师24小时内处理）
效果：实时干预，不让学员"带着问题过夜"

Level 2 — AI+辅导老师协同干预（升级）
触发条件：连续2次Level 1未修复 / 完课率下降
动作：诊断Agent产出详细的薄弱点报告 → 辅导老师基于数据做1对1沟通
（原方案是老师自己判断问题，现在有了数据支撑）
响应时间：4小时内（原方案24小时）

Level 3 — AI预警+教研介入（升级）
触发条件：诊断Agent检测到"标志性风险信号"（如BKT掌握概率连续下降3次）
动作：Agent自动通知教研团队 + 推荐修复方案（如换班型/调整难度）
响应时间：实时预警（原方案依赖老师发现）

升级效果：完课率预计提升8-12个百分点（从~70%到78-82%）

6.7 FSRS自适应复习排期（新增：替代统一复习节奏）

原方案：
所有学员按相同节奏复习 → 效率低，已掌握的知识点浪费精力

B路线升级：
教练Agent利用py-fsrs算法为每个学员计算最优复习间隔
- 掌握度高的知识点：7-14天后首次复习
- 掌握度中的知识点：3-7天后首次复习  
- 掌握度低的知识点：1-3天后首次复习
- 复习间隔指数递增（满足的越好的，周期拉得越长）

效果：学员时间效率提升30%+，薄弱点的复习频次可能是强点的4-5倍

8.6 "思维成长动画"传播引擎（新增：替代/升级8.2小老师视频）

原方案：
小老师视频 → 家长分享 → 朋友圈扩散
限制：制作成本高（老师辅导录制+剪辑），规模化难

B路线新增：
可视化Agent自动生成15秒"思维成长动画"
- 数据来源：诊断Agent全过程记录
- 形式：折线上升 + 雷达演变 + 一句话亮点
- 自动生成：每月/每学期自动为每个学员生成
- 分享动力：家长分享的不是"帮火花打广告"，而是"我家孩子这个月进步好大"

场景：
学期结束时 → 家长收到成长动画 → 自发分享朋友圈/家长群 →
朋友看到"这课真有效果" → 扫码试听

预期效果：转介绍效率比小老师视频提升3-5倍（因为它自动生成、无需人力）

12.5 AI合规风险（新增）

风险6：AI陪练引起家长担忧
- 描述：家长担心AI与未成年学员互动，数据隐私或内容问题
- 概率：中
- 影响：中
- 应对：家长端弹窗说明"AI助教"身份 + 话术预审核 + 提供关闭选项
- 状态：合规确认已做，详见edu/curriculum/compliance-review.md

风险7：AI诊断不准导致学员评估偏差
- 描述：诊断Agent标注薄弱点错误，影响教学决策
- 概率：低（可通过A/B测试验证）
- 影响：中
- 应对：先做100人A/B测试验证准确率 ≥ 80%再全量 + 设置老师人工复核机制
