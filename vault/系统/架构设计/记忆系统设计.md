| 路径 | 内容 |
|------|------|
| `决策/` | 不可逆选择（技术选型、架构定稿） |
| `知识/` | 沉淀积累（研究、架构理解、思维模型） |
| `流程/` | 可执行步骤（SOP、配置、操作手册） |
| `成果/` | 可交付物（报告、产出物、数据） |
| `配置/` | 系统架构元数据 |
| `配置/agents/<agent>.md` | Agent 配置快照 |
| `报告/` | 每日报告、定期产出 |
