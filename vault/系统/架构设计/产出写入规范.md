> **TL;DR** 墨麟OS v3.0 采用 8 根目录零子目录的平坦 Vault 结构，所有 Agent 产出统一使用「业务线｜内容.md」命名规范写入对应目录，旧版多层级目录体系（agent-outputs/、MolinOS-Wiki 等）已全部消灭，禁止任何 Agent 写入旧路径。

## 产出写入规范

> v3.0 平坦 Vault — 8 根目录，零子目录。`agent-outputs/`、`MolinOS-Wiki`、旧版6目录体系全部消灭。

## Vault 根目录（8 个，禁止新增）

```
决策/     — Agent 决策文档
知识/     — 方法论、技术参考、行业洞察
流程/     — 系统架构、执行规范、Profile 配置
成果/     — 完成的任务成果
报告/     — KPI、日报、周报、月度/季度复盘
配置/     — 系统配置文档
产出/     — Agent 运行产出（内容、代码、分析）
学习档案/ — GitHub 精读、论文笔记
```

**零子目录**。文件直接放在 8 大目录下，不建子目录——

已消灭的路径（任何 Agent 写入这些路径即为违规）：
- ~~`产出/edu/`~~ ~~`产出/media/`~~ ~~`产出/side/`~~（profile 子目录）
- ~~`知识库/方法论/`~~ ~~`学习吸收/GitHub精读/`~~（旧版多层级目录）
- ~~`agent-outputs/`~~ ~~`02_Agent_Outputs/`~~ ~~`MolinOS-Wiki/`~~（已被废弃）
- ~~`业务数据/月度复盘/`~~ ~~`Agent档案/`~~（旧根目录名）

## 文件命名规范

格式：`业务线｜具体内容.md`（使用全角竖线 `｜`）

**业务线前缀：**
| 业务线 | 前缀 | 示例 |
|--------|------|------|
| 系统全局 | `系统｜` | `报告/系统｜日报·20260517.md` |
| 元瑶教育 | `元瑶｜` | `成果/元瑶｜火花思维增长方案.md` |
| 银月传媒 | `银月｜` | `产出/银月｜小红书内容矩阵.md` |
| 梅凝出海 | `梅凝｜` | `知识/梅凝｜跨境电商方法论.md` |
| 宋玉创业 | `宋玉｜` | `成果/宋玉｜闲鱼运营日报.md` |
| 玄骨中枢 | `玄骨｜` | `知识/玄骨｜运维经验.md` |
| KPI | `KPI｜` | `报告/KPI｜日报·20260517.md` |

内容标识：日期用 `·YYYYMMDD`，主题用 `·{主题}`，版本号用 `v{N}`。

## 各目录写入规则

| 目录 | 写入内容 | 命名示例 |
|------|---------|---------|
| 决策/ | Agent 的架构决策、技术选型、方向性判断 | `决策/系统｜DeepSeek路由策略.md` |
| 知识/ | 方法论洞察、行业调研、技术参考 | `知识/银月｜小红书流量密码.md` |
| 流程/ | 系统架构文档、执行规范、Agent配置 | `流程/系统｜执行规范.md` |
| 成果/ | 已完成的具体任务交付物 | `成果/元瑶｜课程大纲v2.md` |
| 报告/ | KPI日报/周报/月度复盘/季度报告 | `报告/系统｜日报·20260517.md` |
| 配置/ | 系统配置说明、规则文档 | `配置/系统｜产出写入规范.md` |
| 产出/ | Agent 运行中生成的内容/代码/分析 | `产出/银月｜竞品扫描·20260517.md` |
| 学习档案/ | GitHub精读笔记、论文摘要、学习记录 | `学习档案/系统｜Supertonic精读·20260517.md` |
