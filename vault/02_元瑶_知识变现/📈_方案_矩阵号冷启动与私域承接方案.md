# 元瑶 · 矩阵号冷启动与私域承接方案

**版本**: v1 | **生成**: 2026-05-22
**核心问题**: 无合作方、无自有产品的情况下，如何起号并承接私域leads

---

## 一、问题拆解

```
你有：
  ✅ 内容生产能力（AI内容Agent批量生成）
  ✅ 矩阵号运营能力
  ✅ 私域承接能力（企微）
  
你没有：
  ❌ 合作教育品牌（无CPA合同）
  ❌ 自有体验课产品
  ❌ 试听后给家长的"下一步"
  
结果：
  家长来了 → 没有体验产品 → 流失
  leads积累慢 → 没量 → 没品牌愿意谈CPA
```

**这是一个冷启动死锁**。关键是在 0 产品的状态下，用最小成本跑通「引流→体验→留资」的闭环。

---

## 二、短期方案：用免费AI工具搭建"伪产品"体验

你没产品，但互联网上有大量免费的AI教育工具，它们就是你的"体验课"。

### 2.1 引流钩子：免费AI测评

**不需要开发APP**，只需要一个H5页面 + DeepSeek API：

| 钩子类型 | 用户动作 | 你提供的价值 | 成本 |
|---------|---------|-------------|:----:|
| AI思维测评 | 输入孩子年龄+做几道题 | 输出能力雷达图+薄弱点分析 | API费≈¥0.01/次 |
| AI批改作文 | 拍照上传作文 | AI逐句批改+修改建议 | API费≈¥0.02/次 |
| AI学习规划 | 输入年级+科目 | 生成个性化学习计划 | API费≈¥0.01/次 |
| AI英语口语评估 | 录音 | 口语评分+发音纠正 | 可用免费API |

**技术实现路径**（零成本）:

```
方式A：飞书多维表格（最快速）
  创建表单 → 用户填信息 → 自动化调用DeepSeek API → 返回测评报告
  优点：0开发，30分钟上线
  缺点：体验一般

方式B：微信小程序（推荐）
  用DeepSeek API + 简单的H5页面
  优点：体验好，可留资，可分享裂变
  成本：服务器费≈¥50/月 + API调用费≈¥0.01/次
  时间：1-2天开发

方式C：企微自动化（最快）
  用户添加企微 → 自动回复发送测评链接（跳转飞书表单/腾讯问卷）
  提交后 → AI生成报告 → 企微自动回复
  优点：当天上线
```

**推荐选择方式C（企微+腾讯问卷+DeepSeek API）**，0开发成本，1小时上线。

### 2.2 用户承接流程

```
小红书/抖音笔记 → "免费领AI思维测评"
    ↓
评论区/私信 → "加企微免费领"
    ↓
企微自动通过 + 发送测评链接
    ↓
用户填信息 + 留手机号 → 做测评题
    ↓
AI生成测评报告 → 企微发送
    ↓
报告包含: 能力雷达图 + 薄弱点 + 推荐课程方向
    ↓
家长看到报告 → 对课程产生需求 → 你推CPS链接
```

**关键设计**: 测评报告的最后一页必须是「推荐课程」— 展示火花思维/编程猫/学而思的体验课链接（CPS分佣）。

## 三、没有CPA合同怎么办？先用CPS过渡

CPA需要品牌方对接，门槛高。CPS可以直接注册。

### 3.1 现有可注册的教育CPS平台

| 平台 | 可推广品类 | 佣金比例 | 注册方式 | 到账周期 |
|:----:|-----------|:--------:|---------|:--------:|
| 多多进宝（拼多多） | 教育类课程、学习机 | 5-30% | 直接注册 | T+15 |
| 淘宝联盟 | 学而思、斑马、火花 | 5-20% | 直接注册（需实名） | 月结 |
| 京东联盟 | 科大讯飞学习机、有道 | 3-15% | 直接注册 | 月结 |
| 美团分销 | 教育体验课 | 10-20% | 需入驻 | 月结 |
| 抖音精选联盟 | 各类教育课程 | 10-50% | 抖音后台开通 | T+7 |

**推荐优先注册**: 淘宝联盟 + 抖音精选联盟 → 覆盖大部分AI教育品类

### 3.2 过渡期内操作

```
第1-2周：
  起号发内容 → 引流到企微 → 提供免费AI测评 → 推CPS链接
  目标：验证转化路径，积累前100个leads

第3-4周：
  用已积累的leads数据（留资量+转化率）去谈品牌直签CPA
  话术："我有XX个精准家长leads，转化率X%，要不要签CPA？"

第2月：
  签下1-2个CPA品牌 → 利润率大幅提升
  CPS兜底，CPA增收
```

### 3.3 CPS vs CPA 对比

| 对比项 | CPS（推荐优先） | CPA（目标） |
|:------|:-------------:|:----------:|
| 门槛 | 🟢 低，直接注册 | 🔴 高，需要对接 |
| 收入确定性 | 🟡 看转化 | 🟢 留资即结算 |
| 长尾收益 | 🟢 持续3-6个月 | 🟡 一次性 |
| 适合阶段 | 🟢 冷启动 | 🟢 有量之后 |

**冷启动期先用CPS跑通，有量了再签CPA。**

## 五、最小可行行动清单

### 第1天（今天可做的事）

1. **注册淘宝联盟+抖音精选联盟**（30分钟）
   - 搜索"学而思AI课""火花思维""编程猫"确认CPS佣金比例
   
2. **搭建AI思维测评**（2小时）
   - 用腾讯问卷创建表单：年龄+年级+3道思维题
   - 企微设置自动回复：添加后发送测评链接
   - 手动用DeepSeek/Kimi生成测评报告，发给用户

3. **起第一个小红书号**（1小时）
   - 发布第1篇笔记：「免费领AI思维测评，看看孩子逻辑能力怎么样」
   - 评论区放「加企微免费领」

### 第2-3天

4. **内容铺量**：AI批量生成10篇笔记，每天发2-3篇
5. **测评流程优化**：体验一遍完整流程，确认用户感受

### 第1周结束

6. **验证**：企微好友≥50，送出测评≥20份，CPS出单≥1单
7. **判断**：转化路径通了 → 加码；不通 → 调整钩子或话术

## 六、关键决策点

**要不要花1天开发一个AI测评小程序？**

建议：
- 如果只是想验证需求 → 企微+问卷就够了
- 如果想要长期做 → 花1-2天搭一个简单H5，体验好很多
- 推荐方案：用「腾讯云函数+DeepSeek API+H5页面」，成本¥50/月

**要不要先联系品牌方？**

建议先跑通CPS链路，有了100个leads和转化数据再去谈：
- "我有月均500+精准家长leads，转化率X%，CPA按市场价"
- 有数据才有议价权
