## 二、每类内容的产出SOP

### 2.1 深度研究报告（P0）— 每周1篇

**目的**: AI搜索引擎的高权重引用源
**要求**: 2000-3000字 · 含原始数据出处 · 署名机构
**模板**:

```
标题：2026年[赛道]报考趋势与通过率分析
结构：
  1. 核心结论（200字摘要 — AI会直接截取）
  2. 近年数据对比（3年趋势图 + 表格）
  3. 政策变化解读（引用教育部/人社部文件）
  4. 备考策略建议
  5. 常见误区澄清（QA格式 — AI优先抓取）
  6. 数据出处汇总（含链接）
Schema标记：Article + FAQPage
```

### 2.2 FAQ问答文字（P1）— 每周3-5条

**目的**: 覆盖AI搜索的长尾查询词
**要求**: 每对Q&A 150-300字 · Schema标记FAQPage
**模板**：

```
Q：[完整问题，与AI搜索用户输入一致]
A：[三段式：结论(30字) + 数据(2-3个数字) + 出处]
```

### 2.3 视频号短视频（P1）— 每周3-5条

**目的**: 豆包和微信搜一搜AI优先抓取
**要求**: 1-3分钟 · 字幕文案含核心关键词 · 描述区嵌入FAQ文字
**模板**：

```
标题：XX考试避坑指南｜3个必知
脚本结构：
  开头5秒：抛出问题（"XX考试到底值不值？"）
  正文60秒：3个要点，每个点1个数据支撑
  结尾10秒：CTA（"评论区扣1领备考资料"）
描述区：嵌入200字FAQ文字（GEO素材）
```

### 2.4 小红书图文（长尾）— 每周1条

**目的**: 被Kimi/DeepSeek的图文搜索抓取
**要求**: 清单类内容 · 封面含关键词 · 正文结构化
**模板**：

```
标题：[数字]个XX赛道必知真相
封面：大字标题 + 3个核心数字
正文：分点列出，每点1-2句话
标签：#赛道名 #考试名 #备考
```
