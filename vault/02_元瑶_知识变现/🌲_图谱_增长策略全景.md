# 增长策略项目

元瑶教育增长策略基于AI Agent差异化路线，构建三引擎增长飞轮：AI诊断→个性化学习路径→家长成长报告。从市场分析、用户画像、获客策略到变现模型，实现从流量到留存的全链路闭环。

---

## SCQA 框架

### 情境 (Situation)
中国K-12思维类素质教育市场2025年规模约680亿元（来源：艾瑞咨询《2025中国素质教育行业报告》），同比增长18%，预计2026年突破800亿元。AI Agent在教育中的渗透率从12%预计升至28%（来源：亿欧智库《2025 AI+教育白皮书》）。火花思维已建立三大护城河：9年课程体系、3节无忧退、6对1服务。思维课平均续费率68%，高于传统学科辅导（行业平均约55%）。

### 冲突 (Complication)
尽管市场规模增长强劲，火花思维面临三重增长瓶颈：
1. **获客瓶颈**：传统转介绍率30%已接近行业天花板，纯口碑传播增长放缓
2. **留存瓶颈**：完课率约70%，落后于头部在线教育企业（好未来约82%）；家长无法直观看到孩子进步，"黑箱体验"导致续费犹豫
3. **产能瓶颈**：诊断环节依赖人工（平均20分钟/生），教师产能有限；课后陪伴缺失导致能力进步感知不足

### 问题 (Question)
如何在不大幅增加人力成本的前提下，同时突破获客、留存、产能三重瓶颈？为什么选择AI Agent路线而非传统功能型App升级？

### 答案 (Answer)
从三个维度论证AI Agent路线的必要性：

| 维度 | 功能型App路线（被拒绝） | AI Agent路线（选定） |
|------|------------------------|---------------------|
| 体验深度 | 固定功能，用户被动使用 | 主动诊断+自适应对话，像真人老师一样交互 |
| 传播杠杆 | 无社交传播机制 | 可视化Agent生成"炫耀式"成长报告，家长主动分享 |
| 壁垒厚度 | 竞品可3个月复制 | 需要诊断模型+学习数据积累+个性化算法，竞品追赶周期12-18个月 |
| 成本结构 | 开发成本约50万/模块 | 初期投入较高（约200万），但边际成本趋近于零 |

核心结论：AI Agent路线用"智能交互×社交传播"替代"功能堆砌×广告投放"，在三端（学生端、家长端、教师端）同时创造价值，形成结构性竞争壁垒。

## 决策记录

### ADR-001：选择三引擎飞轮架构

- **决策**：采用"可视化Agent + 诊断Agent + 教练Agent"三引擎飞轮
- **背景**：需要选择一个增长加速方案，备选包括（A）纯营销投放、（B）单一功能优化、（C）三引擎Agent
- **被拒绝方案**：
  - **纯营销投放**：ROI测算低于1.5（行业平均约1.8），且7天内会被竞对跟进，无长期壁垒
  - **单一诊断Agent**：提升完课和续费有效，但无法实现社交传播裂变，增长天花板低
- **选择理由**：三引擎形成闭环——诊断Agent提升质量（留住用户）→可视化Agent实现传播（获取用户）→教练Agent提升LTV（延长生命周期），三者互相强化
- **后果**：开发周期从单一引擎的4周延长至16周（分三期交付）；首期ROI低于单一引擎方案但12个月累计ROI高出3.2倍

### ADR-002：Phase 1仅上线诊断Agent

- **决策**：Phase 1（M1-M3）仅部署诊断Agent，后续引擎依次上线
- **背景**：三引擎同时开发资源冲突，需决定优先顺序
- **被拒绝方案**：同时开发三引擎（资源稀释，每个引擎质量下降）；优先可视化Agent（虽有传播价值，但若后端诊断质量不够，传播反而放大负面口碑）
- **选择理由**：
  - 诊断Agent是飞轮的基础：诊断不准→学习路径错→家长感知差→所有引擎失效
  - 诊断Agent的北极星指标（薄弱知识点定位准确率≥80%）是后续引擎的前提条件
  - Phase 1数据为可视化Agent和教练Agent提供训练语料
- **后果**：传播和LTV的提升推迟3个月；期间需靠现有转介绍机制维持增长

### ADR-003：放弃自研大模型，选择第三方API + 微调

- **决策**：调用通用大模型API（如DeepSeek/GLM），叠加领域微调
- **背景**：自研K-12思维教育大模型 vs 微调通用模型
- **被拒绝方案**：自研基座模型——估算成本5000万+，训练周期12个月，无足够算力资源和教育领域预训练数据
- **选择理由**：K-12思维教育的推理复杂度在通用模型能力范围内，微调可解决领域知识准确性；成本仅为自研的1/20；迭代速度快3倍
- **后果**：受第三方API价格和政策影响；数据安全需额外加密层

## 三引擎增长飞轮

### 引擎A：可视化Agent → 社交传播加速器

**机制**：学员完成一阶段课程 → 诊断Agent输出评估数据 → 可视化Agent将数据转化为"家长成长报告"（包含逻辑能力曲线、薄弱点雷达图、进步排行榜） → 家长分享到朋友圈 → 朋友看到"别人家的孩子" → 好奇试听 → 预约转化。

**预期指标**：转介绍率从30%推高至35-40%。

**具体场景推演——小学员"乐乐"的家长之旅**：

1. **周一晚**：乐乐完成第4节"图形推理"课。系统自动收集：正确率68%（其中空间旋转类正确率仅45%）、平均反应时间4.2秒（高于班级平均3.1秒）、注意力分散记录3次
2. **周二早**：家长打开App，收到可视化Agent推送的"第4周成长报告"。报告亮点：
   - 🏆 "我的模型"雷达图：逻辑推理88分、空间想象65分（标注'建议关注'）、计算速度92分
   - ⏱️ 趋势曲线：空间想象从第1周的42分提升到65分（+23分）
   - 📊 班级对比：乐乐在"持续进步最快榜"排第3名
   - 💡 家长建议：回家玩"乐高旋转拼图"小游戏，每天5分钟针对性训练
3. **周二中午**：家长在朋友圈分享报告截图（可选脱敏模式），配文"没想到娃的空间感进步这么大"
4. **周三**：家长A（朋友）看到后私信询问 → 点击报告内嵌的"试听预约" → 销售跟进

**脱敏模式**：家长可选择"模糊姓名+隐藏班级排名"模式，仅展示能力曲线，保护隐私同时保留炫耀价值。

### 引擎B：诊断Agent → 完课率提升器

**机制**：学员实时作答 → Agent实时分析薄弱点 → 根据图谱定位根本问题（而非表面错误） → 推送给老师精准辅导 → 老师针对性讲解 → 学员掌握更快 → 完课率提升 → 续费率提升。

**预期指标**：完课率从约70%提升到80-85%。

**具体场景推演——小学员"朵朵"的诊断之旅**：

1. **课堂中**：朵朵做"等量代换"练习题，连续3题做错（具体错误：把"3个苹果=1个西瓜"换算成"1个西瓜=3个梨"时逻辑中断）
2. **诊断Agent实时分析**：
   - 表面诊断：等量代换知识点不熟
   - **深层诊断**（关键价值）：朵朵的"传递性推理"心理模型未建立（即A=B, B=C → A=C的推理链条），这是6-7岁儿童常见的认知发展阶段瓶颈（皮亚杰理论），而非注意力或努力问题
   - 自信度评分：92%（误报可能性8%）
3. **推送至老师端**：老师看到诊断卡片 → "朵朵在传递性推理卡壳，建议用实物教具做'三阶传递'游戏，而非继续讲题"
4. **课后反馈**：家长收到诊断Agent生成的"朵朵学习洞察"——"朵朵不是粗心，而是大脑的'逻辑链条'还在搭建中，我们已经安排针对性的游戏化专项练习"

**诊断准确率分层**：
| 层级 | 定义 | 准确率目标 | 达标后动作 |
|------|------|-----------|-----------|
| L1 表层诊断 | 正确识别错误知识点 | ≥95% | 自动反馈 |
| L2 根源诊断 | 识别认知发展瓶颈 | ≥80% | 推送给老师 |
| L3 个性化建议 | 生成针对性游戏方案 | ≥70% | 推送给家长 |

### 引擎C：教练Agent → LTV放大器

**机制**：课后学员打开App → 教练Agent以"智能陪练"形态出现 → 通过对话式练习巩固薄弱点 → 推荐每日5-10分钟游戏 → 能力增长更快 → 家长感知到进步 → 续费意愿增强。

**预期指标**：续费率提升5-10个百分点，周活跃天数从2天提升至4天。

**具体场景推演——小学员"天天"的课后陪练之旅**：

1. **课后第1天**：天天回家后打开App（教练Agent主动触发，非学员打开）。Agent虚拟形象"小元"出现："天天，今天学的'数列规律'我们来玩个侦探游戏吧！"
2. **自适应对话**：
   - 小元："我有一串数字：2, 4, 6, ?, 10。谁偷偷溜走了？"
   - 天天答对后 → "太棒了！那再来个难的：1, 4, 7, 10, ?"
   - 天天答错 → 小元不直接给答案，而是："想想看，4比1多几？7比4多几？每次都多——？"
   - 若连续3次引导后仍错 → Agent调整难度回退一级，记录"等差数列模式识别需要强化"
3. **第3天**：教练Agent根据前2天数据，推送"视觉版数列游戏"（不同模式）
4. **第5天**：Agent检测到掌握度达85%，自动解锁新知识点"等比数列入门"
5. **第7天**：家长收到"本周进步报告"——"天天的数列推理能力从52分提升到78分，超越90%的同龄人"

**教练Agent对话原则**：
- **不直接给答案**：遵循"苏格拉底式引导"，至少3轮追问后才提示
- **情感支持**：答错时不显示"❌"而显示"再想想！"；连续答对后加分和有声效奖励
- **节奏控制**：单次会话不超过15分钟，避免用眼疲劳
- **家长透明**：所有对话记录和家长建议存档，家长可随时查阅

## A/B测试详细方案

### Phase 1 A/B测试：诊断Agent效果验证

| 参数 | 值 | 依据 |
|------|-----|------|
| 样本量 | 实验组200人 + 对照组200人 = 400人 | 基于MDE=5pp，α=0.05，β=0.20，双尾检验 |
| 随机化方式 | 分层随机（按年级/思维基线成绩分层） | 消除年级差异对诊断效果的影响 |
| 时长 | 4周（2周预热 + 2周观测） | 诊断Agent效果在第2周稳定显现 |
| 北极星指标 | 薄弱知识点定位准确率≥80% | 内部专家判断的"临床标准" |
| 核心指标 | ①诊断耗时（人工20min → Agent 3s）②薄弱点修复率≥60% ③完课率+5pp ④家长打开率+10pp | 覆盖学生端、教师端、家长端 |
| 统计显著性 | α=0.05 (Bonferroni校正后α=0.0125，因4个核心指标) | 多重比较校正 |
| MDE（最小可检测效应） | 完课率+5个百分点 | 业务上认为5pp是有意义的改善 |

### 停止规则（避免"偷看"偏差）

| 规则 | 触发条件 | 动作 |
|------|---------|------|
| 早停（正向） | 连续5天p<0.001且效应量Cohen's d>0.5 | 提前结束实验，推全量 |
| 早停（负向） | 连续5天p<0.50且效应量为负（完课率下降或诊断准确率<50%） | 紧急冻结实验，回滚至旧版本 |
| 最大时长 | 实验运行满6周 | 无论显著性如何，停止实验并进行最终分析 |
| 样本耗尽 | 实验组活跃用户不足150人（流失>25%） | 标记为"样本不足"，启动补充实验 |

### Phase 2-3 A/B测试规划

**Phase 2**：可视化Agent验证（M4-M6）
- 样本量：实验组500人 + 对照组500人（需要检测转介绍率的微小变化）
- 时长：8周（社交传播需要更长观察窗口）
- 北极星指标：转介绍率+5pp
- 特殊设计：网络效应隔离——同班级同学随机分配统一实验组/对照组，避免组间干扰

**Phase 3**：教练Agent验证（M7-M12）
- 样本量：实验组300人 + 对照组300人
- 时长：12周（LTV提升需要较长时间观察续费行为）
- 北极星指标：完课率+10pp 且 续费率+8pp
- 特殊设计：需家长知情同意（涉及课后陪练的隐私和屏幕时间）

## 反脆弱机制（Negative Results Plan）

### 如果A/B测试结果为负怎么办？

#### 场景一：诊断Agent准确率<70%（北极星指标未达标）

- **判断标准**：Phase 1 A/B测试结束后，定位准确率低于70%，且置信区间上限低于80%
- **根因分析路径**：
  1. 模型问题？→ 检查微调数据质量（标注一致性、数据量是否充足）
  2. 场景问题？→ 是否因为K-12思维教育的诊断复杂性超出通用模型能力
  3. 工程问题？→ Agent的Prompt设计是否合理？上下文窗口是否过小？
- **应对方案**（按优先级）：
  1. **Pivot计划A**：增加人工标注数据量（从当前5000条增至2万条），重新微调 → 4周内完成
  2. **Pivot计划B**：切换至更强基座模型（如Claude 4或DeepSeek-V4，成本增加约30%）→ 2周内完成切换
  3. **Pivot计划C**：如果模型方法失败，改为"人机协作模式"——Agent做初筛，教研团队做复核，再将复核结果反馈训练Agent → 持续迭代，长期有效
- **回滚条件**：若4周内两次迭代后准确率仍<70%，暂停诊断Agent项目，将资源转向可视化Agent

#### 场景二：完课率无显著提升或下降

- **判断标准**：Phase 1 核心指标"完课率"效应量为负，或效应量<2pp且p>0.3
- **可能原因**：
  - 诊断Agent推送过多（每节课3次以上诊断建议 → 打断学习流畅性）
  - 诊断结果展示太复杂（老师看不懂诊断卡片 → 忽视建议）
  - 对照组也在改善（霍桑效应——对照组老师因关注而更用心）
- **应对方案**：
  1. 调整推送频率：从实时推送改为课后汇总推送
  2. 简化诊断卡片：从包含置信度、根因分析、建议等15项信息缩至3项核心信息
  3. 如果2周内无改善 → 回滚推送机制至"仅当诊断置信度>90%时才推送"

#### 场景三：转介绍率反而下降（可视化Agent引发隐私担忧）

- **可能原因**：家长不愿意分享报告（担心暴露孩子弱项、嫌麻烦、报告设计不美观）
- **应对方案**：
  1. 增加"模板选择"（3种风格：可视化图表风、简约文字风、游戏成就风）
  2. 增加"分享奖励"（分享报告积5分，积分可兑换免费课程）
  3. 如果2周内转介绍率仍低于基线 → 回滚可视化Agent至"仅App内查看，不强制社交传播"

#### 通用回滚与降级机制

| 层级 | 触发条件 | 操作 | 时间 |
|------|---------|------|------|
| L1 功能降级 | 单个Agent准确率<60% | 该Agent回退至"仅内部测试"模式 | <1小时 |
| L2 版本回滚 | Phase核心指标效应量为负 | 全量回退至上一次稳定版本 | <4小时 |
| L3 项目暂停 | 连续两个Phase失败 | 暂停该项目投资，资源重新分配 | <1周 |

### 如果A/B测试结果为正呢？（规模化策略）

- Phase 1 成功（诊断Agent准确率≥80%）→ M4启动可视化Agent开发，并行推进Phase 1全量
- Phase 1+2 成功 → M7前启动教练Agent开发
- 三引擎全部验证通过 → M10开始接入更多科目（当前仅思维/逻辑 → 扩展至编程、语言）
- 数据飞轮启动 → 每收集100万条诊断记录，重新微调一次模型 → 形成持续自我优化的数据壁垒
