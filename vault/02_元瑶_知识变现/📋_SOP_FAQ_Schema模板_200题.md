**目标**: 200个结构化FAQ页面 → 被豆包/Kimi/DeepSeek在回答中引用
**赛道**: 会计/CPA（优先）→ 后续扩展至公考/AI职场
**Schema类型**: FAQPage（Google/百度/豆包/Kimi均支持）

## 一、Schema JSON-LD模板

### 1.1 单页单问题（推荐 — 收录率最高）

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": {
    "@type": "Question",
    "name": "完整问题文本",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "三段式答案。结论句不超过30字。数据支撑含2-3个数字。权威出处带链接。"
    }
  }
}
```

### 1.2 单页多问题（节省页面数）

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "问题1",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "答案1"
      }
    },
    {
      "@type": "Question",
      "name": "问题2",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "答案2"
      }
    }
  ]
}
```

## 二、FAQ内容模板（三段式）

```
Q：[完整问题，与AI搜索用户输入一致]
A：
[结论句] 30字以内，直接回答。
[数据支撑] 2-3个数字，带来源。如有对比数据更佳。
[权威出处] 机构名 / 政策文件名 / 官网链接。
```

**示例**：

```
Q：CPA考试一年考几次？
A：
[结论] CPA考试每年只考一次。
[数据] 2026年CPA考试时间为8月28-30日，报名时间为4月8-30日。
[出处] 中国注册会计师协会官网（cicpa.org.cn）
```

## 七、质检标准

每对FAQ必须满足：

- [ ] Q与AI搜索真实输入一致（建议从豆包搜索下拉词提取）
- [ ] A的三段式结构完整（结论+数据+出处）
- [ ] 结论句 ≤ 30字
- [ ] 数据至少包含2个数字
- [ ] 出处链接可访问
- [ ] Schema JSON-LD校验通过（validator.schema.org）
- [ ] 不包含主观评价（"我觉得""据说"）
- [ ] 不直接贬低竞品
- [ ] 每对Q&A 150-300字
- [ ] 答案不违反广告法（不使用"第一""最"等绝对化用语）
