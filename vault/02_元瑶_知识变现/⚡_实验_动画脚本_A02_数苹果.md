# A02 · 数苹果 · 动画脚本

## 角色设定

| 角色 | 外观 | 性格 |
|:----:|------|------|
| 咕咚（主角） | 圆滚滚的蓝色小怪兽，大眼睛，两个小角 | 好奇、活泼、爱吃苹果 |
| 苹果 | 红色圆苹果，有可爱的表情 | 友善、排队时微微晃动 |

**美术风格提示（给即梦）**：
> 儿童动画风格，明亮柔和的色彩，低多边形3D或高品质2D手绘风，白色背景或浅色渐变背景，角色边缘柔化，画面干净通透，类似《嗨！道奇》或《超级宝贝JoJo》的美术质感。

---

## 场景分镜（共5个场景，总长约60秒）

### 场景①：开场打招呼（约8秒）

| 元素 | 描述 |
|:----|------|
| 画面 | 浅蓝色渐变背景，画面中央是咕咚（正面全身），开心地挥动小爪子 |
| 动作 | 咕咚蹦跳一下，眼睛亮起来 |
| 旁白 | （童趣女声，语速慢）"小朋友你好！我是咕咚～今天我们来数苹果啦！" |
| 即梦Prompt | 一个可爱的蓝色小怪兽站在浅蓝色渐变背景中央，开心挥手，儿童动画风格，明亮色彩，圆润造型，全身镜头，白色柔和光照 |

### 场景②：1个苹果 — 点数示范（约12秒）

| 元素 | 描述 |
|:----|------|
| 画面 | 场景切换，咕咚面前出现一个红苹果（飘浮在空气中，微微旋转） |
| 动作 | 咕咚伸出食指，指着苹果数。苹果上浮现数字"1" |
| 旁白 | （慢速，配合动作）"一个苹果，这是 1。" |
| 即梦Prompt | 一个蓝色小怪兽伸出爪子指着一个红苹果，苹果旁边浮现发光的数字1，儿童动画，明亮色彩，简洁构图，近景 |

### 场景③：2-5个苹果 — 逐个点数（约25秒）

逐帧增加苹果数量，每帧8秒：

**3a — 2个苹果（8秒）**
| 画面 | 两个苹果并排出现，咕咚从左指到右 |
| 旁白 | "两个苹果，1～2，这是 2。" |
| 即梦Prompt | 蓝色小怪兽面前有两个红苹果，小怪兽伸爪子从左指到右，数字2发光浮现在苹果旁边 |

**3b — 3个苹果（8秒）**
| 画面 | 三个苹果排成一行，咕咚逐个点数：1、2、3 |
| 旁白 | "三个苹果，1～2～3，这是 3。" |
| 即梦Prompt | 三个红苹果排成一行，蓝色小怪兽逐个点数它们，数字3发光浮现在苹果上方，儿童动画风格 |

### 场景④：4和5 — 比一比谁多（约10秒）

| 元素 | 描述 |
|:----|------|
| 画面 | 左右两堆苹果：左边4个，右边5个 |
| 动作 | 咕咚站在中间，先指左边再指右边，5个的那堆跳了一下（表示更多） |
| 旁白 | "四个苹果是4。五个苹果是5～五个比四个多一个！" |
| 即梦Prompt | 蓝色小怪兽站在中间，左边4个红苹果右边5个红苹果，小怪兽指向右边，儿童动画场景，彩色，柔和光照 |

### 场景⑤：结尾互动（约5秒）

| 元素 | 描述 |
|:----|------|
| 画面 | 回到咕咚正面特写，5个苹果排成一排在他头顶飞过，每个标着1-5 |
| 动作 | 咕咚拍手欢呼，眼睛弯弯 |
| 旁白 | "你学会了吗？和咕咚一起再数一遍吧～拜拜！" |
| 即梦Prompt | 蓝色小怪兽开心拍手，头顶有5个红苹果排成一行，每个苹果上分别标注数字1到5，儿童动画，温馨欢快氛围 |

## 即梦生成建议

### 最佳生成策略

| 策略 | 说明 |
|:----|------|
| 拆帧生成 | 每场景独立生成视频片段，后期合成 |
| 首帧锁定角色 | 首场景先生成角色形象参考，后续场景保持一致性 |
| 图生视频优先 | 先用AI生成咕咚的角色定妆图，再以图为起点生成视频 |
| 旁白后期配音 | 视频生成后加TTS配音（Edge TTS童声或元瑶TTS） |

### 角色定妆Prompt（先生成这个）

> 一个可爱的卡通蓝色小怪兽角色，通体蓝色，圆滚滚的身体，大大的眼睛，头顶有两个小角，表情友善好奇，儿童动画风格，白底全身图，无背景，高清晰度，柔和的色彩，扁平风格。

### 重点提示

- 每段Prompt结尾加 **"儿童动画风格，明亮色彩，白色渐变背景，无文字污渍，高清"** 统一画风
- 避免复杂动作（如精确的手指点数），AI视频生成暂时做不好微操。旁白用后期配音完成"手口一致"的效果
- 苹果用简约红球+高光+小绿叶即可，不要复杂纹理
- 数字发光浮现有助于孩子聚焦注意力
