## 二、信息筛选规则

### 原始数据 → 候选选题（三道筛）

**第一筛：相关性筛**

通过标准（任一满足即可）：
- 关键词匹配：命中墨麟业务关键词池（AI教育 / AI Agent / 出海 / 台湾 / 内容营销）
- 领域相关：话题属于在线教育 / AI工具 / 跨境电商 / 内容创作
- 用户相关：目标用户（家长 / 创业者 / 营销人）可能感兴趣

未通过 → 丢弃，不进入下一筛。

**第二筛：价值筛**

评分维度：
| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 热度 | 30% | 搜索量/阅读量/互动量相对值（0-100） |
| 时效性 | 20% | 是否本周热点 / 趋势上升中 |
| 差异化 | 20% | 与已发布内容的差异度 |
| 转化潜力 | 15% | 是否与产品/服务相关 |
| 长青度 | 15% | 是否能沉淀为常青内容 |

通过标准：总分 ≥ 60。

**第三筛：冲突筛**

检查项：
- 是否已被本周排期覆盖 → 跳过或换角度
- 是否已被近期（7天内）内容覆盖 → 降低优先级或换角度
- 是否与品牌立场冲突 → 丢弃

## 三、选题优先级矩阵

基于 热度 × 转化潜力 四象限：

```
                 转化潜力
                低 ←---------→ 高
         ┌─────────────────────────┐
    高   │  D象限               A象限 │
         │  热点跟风              最佳选题  │
 热度    │  优先级：P2           优先级：P0  │
         │                         │
         ├─────────────────────────┤
    低   │  C象限               B象限 │
         │  低价值              长尾选题  │
         │  优先级：P3           优先级：P1  │
         └─────────────────────────┘
```

优先级定义：
- **P0（今日必出）**：A 象限，高热度 + 高转化潜力，立即生产
- **P1（今日可出）**：B 和 D 象限，高单项分，排入今日或明日排期
- **P2（本周观察）**：潜力股，放入观察池，持续跟踪
- **P3（非重点关注）**：C 象限，仅存档

      "title": "选题标题",
      "angle": "差异化角度",

      "total_score": 89,

### 排期文件

写入 Obsidian `Agents/内容Agent/排期.md`，格式：

```markdown
# 内容排期 YYYY-MM-DD

## 今日 P0
- [ ] 选题A → 小红书 14:00 / 抖音 18:00
- [ ] 选题B → 公众号 12:00

## 今日 P1（选做）
- [ ] 选题C → LINE 推播 20:00

## 观察池
- 选题D（等待热度上升）
- 选题E（等待相关数据）
```

## 五、与现有系统的集成

### 集成到飞轮管线

```
06:30-07:30  数据采集（各源）
    ↕ Lead SOP 三道筛
07:30-08:00  生成选题池 + 排期
    ↕ 
08:00-09:00  内容生产（Execution SOP 启动）
```

### 集成到 Content SOP

- 在 `content-sop-pack` Execution SOP 的 Step 1（选题确认）中，检查 `relay/topic_pool_{date}.json`
- 如果当天选题池不存在（飞轮断裂），自动触发 Escalation
