# 内容 Agent 发布模板集

## 小红书帖子模板

### 模板 1：干货/教程类
```markdown
# 标题（含关键词 + 数字 + 情绪）

**正文结构：**

[钩子：3行内制造痛点或悬念]
你是不是也遇到过这种情况：{用户痛点场景描述}

[价值铺垫：为什么这个问题重要]
其实很多人不知道，{核心洞察}

[核心内容：分点展开，每点1-2段]
1️⃣ {第一点}
{详细展开}

2️⃣ {第二点}
{详细展开}

3️⃣ {第三点}
{详细展开}

[情绪推进]
{一个真实感的故事/案例，让读者产生共鸣}

[CTA]
💬 你有遇到类似问题吗？评论区聊聊
❤️ 觉得有用的话点个赞吧
📌 收藏起来下次用得上

---

#标签 #关键词1 #关键词2 #关键词3
```

### 模板 2：测评/对比类
```markdown
# {产品A} vs {产品B}：{核心差异点}，选哪个？

**正文结构：**

[痛点引入]
{用户在两难中的纠结场景}

[对比表格]
| 维度 | {产品A} | {产品B} |
|------|---------|---------|
| 价格 | ¥XX | ¥XX |
| 功能 | {关键功能} | {关键功能} |
| 适合 | {目标用户} | {目标用户} |

[选择建议]
🏆 如果你{场景A} → 选{产品A}
🏆 如果你{场景B} → 选{产品B}

[CTA]
你用的哪个？评论区告诉我
```

### 模板 3：故事/经历类
```markdown
# {数字}天，我终于{核心变化/成果}

**正文结构：**

[悬念钩子]
从{旧状态}到{新状态}，我只用了{N}天。

[背景铺垫]
过去我一直被{问题}困扰……（2-3段）

[转折点]
直到有一天，我发现了{关键方法}

[行动过程]
第1步：{做了什么}
第2步：{做了什么}
第3步：{做了什么}

[成果展示]
现在的我：{具体成果}（数据/截图/对比）

[总结CTA]
这段经历让我明白：{核心道理}
如果你也在{同状态}，不妨试试这个方法。
```


## 短视频脚本模板

### 模板 1：知识科普（60s）

```
[0-3s] 钩子
视觉：{吸引注意的画面，如文字弹幕/实物演示}
配音：{挑战认知的问题或惊人事实}

[3-10s] 问题引入
视觉：{用户痛点场景}
配音：{描述这个问题有多普遍}

[10-40s] 核心内容
视觉：{每5s切换画面，配合讲解}
配音：{分3-4个要点讲解}
每5s一个信息点，节奏要快

[40-50s] 价值总结
视觉：{核心结论放文字}
配音：{一句话总结}

[50-60s] CTA
视觉：{指向关注/点赞的手势}
配音：{引导互动}
```

## 自检清单（发布前必过）

### 通用检查
- [ ] 标题是否包含核心关键词？
- [ ] 前3段/3秒是否有钩子？
- [ ] 是否有明确的CTA？
- [ ] 长度符合平台限制？
- [ ] 配图/封面已就绪？

### 平台特定
- [ ] 小红书：话题标签是否加满？
- [ ] 公众号：摘要是否写好了？
- [ ] 短视频：前3秒是否抓住注意力？
- [ ] SEO：H标签层级是否正确？
- [ ] LINE：链接是否正确？退订提示？

### 品质检查
- [ ] 无事实错误或数据幻觉
- [ ] 来源标注清楚
- [ ] 品牌名称书写正确
- [ ] 无敏感/违规内容
- [ ] 语气符合品牌调性
