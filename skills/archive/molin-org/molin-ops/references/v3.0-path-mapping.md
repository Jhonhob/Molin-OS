## 批量替换顺序（重要）

升级包文件时，按以下顺序替换，避免交叉污染：

1. **根路径替换**：`~/MolinOS-Wiki` → iCloud 完整路径
2. **目录名替换**：`知识库/` → `知识/`、`业务数据/` → `报告/`
3. **子目录消灭**：`{agent_id}/{topic}.md` → `{业务线}｜{topic}.md`
4. **中文化**：`mobi_edu` → `元瑶`、`mobi_content` → `银月`
