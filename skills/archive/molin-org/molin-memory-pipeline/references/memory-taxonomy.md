# 记忆四层架构（L1-L4 Taxonomy）

来源: Molin-OS 审计报告 + 落地写入 Obsidian `流程/记忆四层架构规范.md`

## 四层定义

| 层级 | 名称 | 载体 | 深度 | 时效 | 清理规则 |
|------|------|------|------|------|----------|
| 🔴 L1 | 工作记忆 | 飞书对话上下文 / Session | 摘要级 | 当日 | 24h 自动清理 |
| 🟡 L2 | 情节记忆 | Supermemory（向量检索） | 300-800字 | 近期 | 30天未调用→蒸馏到L3 |
| 🟢 L3 | 语义记忆 | Obsidian 知识/ 学习档案/ | 1000-5000字 | 长期 | 永久保留，定期回顾 |
| 🔵 L4 | 程序记忆 | SKILL.md 文件 | 可执行规范 | 永久 | 测试验证后合并 |

## 分类标签规范

所有 Obsidian 文件必须包含:
```yaml
tags: [记忆层级(L1/L2/L3/L4), 来源(对话/审计/学习/手动), 可信度(已验证/待验证/实验性)]
```

## 蒸馏路径

```
L2(Supermemory) → 30天未调用 → 蒸馏为 L3(Obsidian)
L3(Obsidian) → 3+次引用 + 2+次实践验证 → AutoDream提案 → L4(SKILL.md)
```

## 禁止规则
- L1 不进 Obsidian（只在 Supermemory）
- L3 不能直接改 L4（必须通过 AutoDream 提案）
- 学习结果不混入业务产出目录（必须在 `学习档案/` 下独立存放）
