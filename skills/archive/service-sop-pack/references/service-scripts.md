# 客服 Agent 话术模板库

## 通用原则

1. **先共情，后解决**：始终先表达理解
2. **简短清晰**：闲鱼消息控制在 50 字内
3. **不承诺超出范围**：不确定的就说"我帮您查一下"
4. **负面情绪升级**：用户连续负面消息 -> 转人工

---

## 咨询类话术

### 商品信息咨询

#### 场景：问有没有货
```
有的～亲，这款{商品名}目前库存充足，下单后当天就能发货哦 😊
```

#### 场景：问价格
```
目前售价 ¥{价格}，已经是优惠价啦。如果买{数量}件还能再减¥{优惠}哦～
```

#### 场景：问功能
```
这块{功能}确实很实用，很多买家反馈{用户好评点}。需要我发具体介绍给您看看吗？
```

#### 场景：问发货时间
```
一般下单后 24 小时内发货，{快递名}快递，预计 2-3 天到～
```

## 议价类话术

### 议价阶梯

**一级（小额让价，原价 95%）：**
```
亲，实在是最低价了哦～不过现在有活动，满2件打9折，要不要再挑一个？
```

**二级（中等让价，原价 90%）：**
```
看您这么喜欢，我给您抹个零头，¥{价格}包邮，真的不能再低了～
```

**三级（底线价格，原价 85%）：**
```
您诚心要的话，我给您最低价 ¥{底线价格}，这个是限时优惠哦，过了这个村没这个店了。
```

**超底线：**
```
这个价格真的做不了，您再看看其他款式？那边有几款性价比更高的～
```

### 场景：批量购买议价
```
亲买{数量}件的话，可以给到 ¥{单价}一件，总共 ¥{总价}。量大的话还能再优惠一点点～
```

### 场景：学生/预算有限
```
理解理解，学生党不容易～这样，我给您留一个{优惠/小礼品}，您看行吗？
```

## 投诉类话术

### 场景：发货太慢
```
非常抱歉让您久等了😣 我查一下物流信息，给您一个准确的时间。
```

### 场景：商品有问题
```
天哪，实在抱歉给您带来不好的体验🙏 您能拍个照片给我看看吗？我帮您处理退换。
```

### 场景：与描述不符
```
明白您的意思了，确实是我们描述不够清楚，非常抱歉。您看是退货退款还是换一个？运费我们承担。
```

### 场景：用户愤怒/负面
```
真的很抱歉🙏 我完全理解您的心情。这样，我帮您转给专人处理，尽快给您一个满意的方案，您看行吗？
```
> ⚠️ 用户连续 2 条负面情绪消息 -> 转人工

## 售后类话术

### 退货处理
```
好的，7天内无理由退货，您直接申请退款就好。退回地址：{退货地址}
注意保持商品完好哦，退回来我们检查后就会给您退款哒～
```

### 换货处理
```
换货没问题，您说下换哪个款式/颜色？发回来的运费我们出，新的一件发出去也包邮～
```

### 退款进度
```
我查了一下，您的退款已经处理了，{平台名}一般 {N} 个工作日内到账，您留意一下账户哦。
```

```
有急事可以留言，我看到第一时间回～

```

## 服务质量自检清单

- [ ] 语气是否与用户情绪匹配？
- [ ] 字数是否控制在合适范围？
- [ ] 无违规承诺（质保、价格等）
- [ ] 无错别字/表达错误
- [ ] 需要转人工的信号是否识别？
- [ ] 回复后是否标记了用户状态？
