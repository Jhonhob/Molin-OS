# Vault 结构参考（v3.0 平坦结构）

## 顶层目录（全中文 · 零子目录）

```
Vault/
├── 决策/       ← 不可逆选择
├── 知识/       ← 沉淀认知
├── 流程/       ← 可执行步骤
├── 成果/       ← 可交付物
├── 报告/       ← KPI看板、定期报告（平坦）
├── 配置/       ← 系统架构元数据（平坦）
├── 产出/       ← Agent 结构化输出（平坦）
└── 学习档案/   ← GitHub精读/学习笔记（平坦）
```

**零子目录。** 文件命名 `业务线｜具体内容.md` 区分归属。

## Agent 输出路径规则（v3.0）

所有 Agent 输出直接写入 `产出/`，不建子目录：

```
产出/
  系统｜日报.md               ← Hermes 系统日报（滚动更新）
  银月｜日报.md               ← 媒体日报（滚动更新）
  玄骨｜日报.md               ← 财务日报（滚动更新）
  宋玉｜日报.md               ← 副业日报（滚动更新）
  元瑶｜AB测试方案.md          ← 教育专题输出
  元瑶｜增长策略v4.md          ← 教育方案
```

**不再建各Agent子目录。不再有 github-absorb/。**

## 文件命名规范（v3.0）

```
业务线｜具体内容.md
```

- 分隔符: 全角竖线 `｜`
- 业务线: `系统` `元瑶`(edu) `银月`(media) `梅凝`(global) `宋玉`(side) `玄骨`(shared) `KPI`
- 日报: 单文件滚动更新，不按日期新建
- 一次性报告: 可带日期后缀，如 `KPI｜周报·0511-0516.md`
- 禁止: 子目录、`·` 分隔符、`02_` 编号前缀、英文目录名
