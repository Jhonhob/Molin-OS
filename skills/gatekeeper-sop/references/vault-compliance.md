# Vault 合规检查参考（v3.0 平坦结构）

## 检查脚本

位置: `~/Molin-OS/scripts/vault_health_check.py`

自动作为 Cron 在 22:00 复盘前运行。也可手动执行：
```bash
cd ~/Molin-OS && python3 scripts/vault_health_check.py
```

## 允许的顶层目录

```
决策/          ← 不可逆选择
知识/          ← 沉淀认知
流程/          ← 可执行步骤
成果/          ← 可交付物
报告/          ← KPI看板、定期报告（平坦，无子目录）
配置/          ← 系统架构元数据（平坦，无子目录）
产出/          ← Agent 结构化输出（平坦，无子目录）
学习档案/      ← 学习笔记/GitHub精读（平坦，无子目录）
```

**零子目录。** `报告/KPI看板/` `配置/agents/` `学习档案/{agent_id}/github-absorb/` `产出/{agent_id}/` 全部消灭。

## 明确禁止的路径

```
❌ agent-outputs/       — 旧版路径，已删除
❌ 02_Agent_Outputs/    — 旧版路径，已删除
❌ Agents/              — 旧版路径，已删除
❌ System/              — 旧版路径，已删除
❌ Daily/               — 旧版路径，已删除
❌ 产出/*/              — 禁止子目录
❌ 学习档案/*/          — 禁止子目录
❌ 报告/KPI看板/        — 禁止子目录
❌ Archive/             — 只读历史备份（不动）
```

## 文件命名规则（v3.0）

```
业务线｜具体内容.md
```

- Agent 产出: `产出/业务线｜{主题}.md`
- 日报: `产出/业务线｜日报.md`（滚动更新单文件）
- 学习笔记: `学习档案/业务线｜{主题}·{日期}.md`
- KPI看板: `报告/KPI｜{类型}·{日期}.md`
- 系统文档: `配置/系统｜{主题}.md` `流程/系统｜{主题}.md`
