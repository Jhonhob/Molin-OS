## 一、Lead SOP（教育需求获取）

### 需求来源

| 来源 | 方式 | 优先级 |
|------|------|--------|
| 市场热点 | 教育类热搜/热门课程方向 | P0 |
| 用户反馈 | 学习过程中的问题/难点统计 | P1 |
| 竞品课程 | 同类教育产品课程目录 | P1 |
| 内容 Agent 联动 | 从内容表现中发现教育需求 | P2 |

### 需求评估

| 评估维度 | 权重 | 说明 |
|----------|------|------|
| 市场需求度 | 30% | 搜索量/咨询量/热度 |
| 知识壁垒 | 25% | 是否能建立差异化内容 |
| 可教学性 | 20% | 能否结构化输出为课程 |
| 变现潜力 | 15% | 是否有付费意愿 |
| 持续性 | 10% | 能否持续迭代更新 |

## 二、Execution SOP（课程内容生产流程）

### 课程设计流水线

```
需求确认 → 课程大纲 → 知识图谱 → 单元内容 → 练习/测验 → 输出标准格式
```

### Step 1: 课程大纲设计

- 确定目标受众（学员画像）
- 设计学习目标（学完能做什么）
- 规划模块结构（4-8 个单元为佳）
- 设定难度递进曲线

### Step 2: 知识图谱

```
[预备知识] → [基础概念] → [核心方法] → [高级技巧] → [实战项目]
                                                    ↓
                                           [评估测试] ← [知识巩固]
```

每个节点包含：
- 学习目标
- 核心概念（3-5 个）
- 预计学习时长
- 前置依赖

### Step 3: 单元内容生产

每个单元包含：
```yaml
单元名称: "xxx"
学习目标: "完成本单元后，学员能够..."
核心概念: ["概念1", "概念2", ...]
内容:
  - 讲解部分（图文/视频脚本）
  - 示例/案例（至少1个）
  - 练习（2-3 道）
  - 总结
延伸阅读: ["链接1", "链接2"]
预计时长: "30分钟"
```

### Step 4: 练习与测验

- 每单元至少 2 道练习题
- 每模块结束后 5 题小测验
- 课程结束 10 题综合测验
- 练习需附带解析

### Step 5: 输出格式

课程内容写入 Obsidian `Agents/墨学教育/课程/{course_name}/`：

```
课程大纲.md
单元_01_基础概念.md
单元_02_核心方法.md
...
练习题.md
测验.md
```

## 三、QA SOP（教育内容质检）

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 知识准确性 | 30% | 内容正确，无知识性错误 |
| 教学逻辑 | 20% | 递进合理，无逻辑跳跃 |
| 可理解性 | 20% | 语言清晰，示例恰当 |
| 完整性 | 15% | 每个单元都有练习+总结 |
| 差异化 | 15% | 与市面课程有不同角度 |

### 否决条件
- 知识性错误（必须修正）
- 无法验证的绝对化论断
- 侵犯版权（直接复制他人课程内容）

## 四、Escalation SOP

| 场景 | 触发 | 动作 |
|------|------|------|
| 内容被指错误 | 用户/专家反馈 | L1 通知 + 追溯修正 |
| 课程完成度低 | 学员留存 < 30% | 重新设计课程结构 |
| 知识点不完整 | 发现知识缺口 | 补充单元 |

## 六、与内容管道的集成

```
教育 Agent 课程产出
    ↓ relay/education_{course}.json 
内容 Agent 将课程内容转化为：
    ↓ 小红书科普帖
    ↓ 公众号深度文
    ↓ 短视频讲解
    ↓ LINE 推播引流
```

教育内容天然适合多形态分发，是内容 Agent 的高质量选题来源。
