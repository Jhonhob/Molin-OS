## 适用 Agent
- 墨韵IP (ip_manager.py)

---

## 一、Lead SOP（品牌保护需求获取）

### 需求来源

| 来源 | 方式 | 优先级 |
|------|------|--------|
| Agent 产出检查 | 各 Agent 产出中的品牌使用是否规范 | P0（每次产出检查） |
| 品牌上新 | 新产品/新市场推出前 | P1 |
| IP 授权请求 | 第三方申请使用品牌/IP | P1 |
| 版权风险 | 外部侵权监测 | P1 |
| 商标续展 | 商标到期提醒 | P2（周期性） |

### 品牌检查触发点

所有 Agent 输出前，Gatekeeper 终检中的"品牌一致性"维度由墨韵 IP SOP 定义标准：

| 检查项 | 标准 | 扣分规则 |
|--------|------|----------|
| 品牌名称 | "墨麟" / "Molin" / "Molin-OS" 书写正确 | 每处错误 -5 |
| Logo 使用 | 使用已注册版本的 Logo | 旧版/变形 -10 |
| 品牌色 | 主色/辅色/文字色与色卡一致 | 每处偏差 -3 |
| 字体 | 品牌指定字体 | 非标准字体 -5 |
| 调性 | 专业/亲和/创新 | 风格偏离 -8 |

## 二、Execution SOP（品牌管理流程）

### 品牌管理流水线

```
品牌标准定义 → 产出检查 → 异常处理 → 品牌演进 → 定期审计
```

### Step 1: 品牌标准定义

品牌指南必须包含：
```yaml
brand:
  name:
    chinese: "墨麟"
    english: "Molin"
    full: "墨麟AI集团"
    tagline: "让AI经营企业"
  colors:
    primary: "#??? / ???"  # 品牌主色
    secondary: ["#???", "#???"]  # 辅色调色板
    text: "#???"
    background: "#???"
  typography:
    primary_font: "字体名称"
    fallback: "系统字体"
  logo:
    primary: "标准版本路径"
    icon: "图标版本路径"
    minimum_size: "最小使用尺寸"
    clear_space: "安全距离规则"
  tone:
    formal: "正式场合调性"
    casual: "社交媒体调性"
    forbidden: "禁止使用的表达"
```

### Step 2: 产出检查

检查点：
1. 所有对外内容（内容 Agent / 设计 Agent / 视频 Agent）产出
2. 新市场/新平台首次使用品牌时（出海 Agent）
3. 品牌材料更新时

检查方式：
- gatekeeper-sop 终检中触发品牌检查
- 检查结果记录在 `relay/brand_check_{date}.json`

### Step 3: 异常处理
- 品牌使用错误 → 通知产出 Agent 修正
- 严重品牌偏离 → 暂停发布 + L1 通知
- 第三方侵权 → 取证 + 法务联动

### Step 4: 品牌演进
- 品牌资产定期更新（每季度）
- 新市场品牌本地化评估（出海时）

## 三、QA SOP（品牌质量质检）

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 品牌识别度 | 25% | Logo/色/字体是否被正确识别？ |
| 一致性 | 25% | 跨平台/跨内容是否保持统一？ |
| 差异化 | 20% | 是否清晰区分于竞品？ |
| 本地化适配 | 15% | 海外市场品牌名称/调性是否适配？ |
| 合规风险 | 15% | 商标/版权是否有法律风险？ |

---

## 四、Escalation SOP

| 场景 | 触发 | 动作 |
|------|------|------|
| 严重品牌违规 | 多次警告后仍出现 | 暂停 Agent + L2 审批 |
| 商标被抢注 | 第三方注册相似商标 | L3 董事会：法务介入 |
| 品牌声誉风险 | 负面舆情关联品牌 | L2 审批 + 公关应对 |

## 六、集成

```

    ↓ 品牌维度检查（规则由墨韵IP定义）

```

### 内容/设计/视频集成
```
各 Agent 产出
    ↓ frontmatter 中的品牌参数
墨韵IP 品牌检查
    ↓ 通过
继续分发
```
