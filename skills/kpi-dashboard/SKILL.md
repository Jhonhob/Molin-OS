# KPI 看板生成器

## 概述

本技能将 `relay/kpi/` 中的结构化 KPI 数据转化为可读的经营看板，写入 Obsidian。

看板分层：
1. **日看板** — 今日快照（随 22:00 复盘生成）
2. **周看板** — 本周趋势（随周日 21:00 增长复盘生成）
3. **全景看板** — 所有 Agent 综合视图（按需生成）

---

## 四、生成方式

### 手动生成
```bash
# 直接对话中要求：
"生成今日 KPI 看板"
"生成本周 KPI 看板"
"更新全景经营看板"
```

### Cron 自动化

| 时间 | 看板类型 | 集成方式 |
|------|----------|----------|
| 22:10（复盘后） | 日看板 | 复盘 Cron 中增加看板生成步骤 |
| 周日 21:30（增长后） | 周看板 | 增长复盘 Cron 中增加看板生成步骤 |
| 按需 | 全景看板 | 手动触发 |

---

## 五、数据流向

```
22:00 复盘采集 → relay/kpi/{agent}_{date}.json
                      ↓
22:10 看板生成 → 读取 relay/kpi/ 全量数据
                      ↓
              ASCII 趋势图 + 表格
                      ↓
              Obsidian Agents/KPI看板/{date}/{agent}_看板.md
```

## 六、参考

- 数据来源：`relay/kpi/` 目录
- 看板存放：Obsidian `Agents/KPI看板/`
- KPI 定义：`skill_view('kpi-tracker')`
- 复盘 Cron：22:00 每日复盘
