## 二、Execution SOP（本地化执行流程）

### 本地化流水线

```
内容输入（简体中文） → 语义级转换 → 平台适配 → 本地合规检查 → 定时分发
```

### Step 1: 语义级转换（非简单简繁互换）

本地化层级：

| 层级 | 说明 | 示例 |
|------|------|------|
| L1：文字转换 | 简转繁（用词一致） | 打印机 → 印表機 |
| L2：用词本地化 | 替换台湾常用词 | 人工智能 → AI / 人工智慧 |
| L3：表达习惯 | 句式和语序调优 | "我们建议"→"建議您" |
| L4：文化适配 | 本地化案例/比喻/梗 | 替换国内案例为台湾本地案例 |

标准路径：
```
大陆内容 → L1 文字转换 → L2 用词本地化 → L3 表达调优 → 台湾正式内容
```

需要 L4 时：调用 supermemory 获取台湾本地案例/文化参考。

### Step 2: 平台适配

| 平台 | 内容形态偏好 | 字数/时长限制 | 分发时间 |
|------|-------------|--------------|----------|
| Vocus | 深度长文 + 观点输出 | 1000-3000 字 | 平日 12:00 / 20:00 |
| LINE 推播 | 短讯 + 卡片链接 | 200 字内 | 平日 20:00-21:00 |
| Facebook 贴文 | 中长篇 + 图片/视频 | 300-800 字 | 平日 10:00 / 20:00 |
| YouTube | 中视频（3-10min） | 不限 | 週末 10:00 |
| Instagram | 图文/Reels | 短文 + 视觉 | 平日 19:00-21:00 |

### Step 3: 本地合规检查

- 检查台湾 NCC / 数位部相关规定
- 金融/医疗/教育类内容是否有当地许可要求
- 广告标注规范（台湾需明确标注「廣告」）
- 避免大陆敏感词汇/政治议题
- 仅用「台湾」或「台灣地區」称谓规范

## 三、QA SOP（本地化质检）

### 评分维度

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 语言准确性 | 25% | 用词是否正确？无简体残留？ |
| 文化适配度 | 20% | 案例/比喻/数据是否本地化？ |
| 平台适配度 | 20% | 格式/长度/图片是否符合平台习惯？ |
| 合规安全 | 20% | 无敏感词/政治议题/未授权内容？ |
| 品牌一致性 | 15% | 品牌名称/调性是否跨市场统一？ |

### 否决条件
- 简体字残留（技术性否决，必须全繁）
- 大陆敏感词汇/政治比喻
- 冒充本地创作者或虚假授权

### 阈值动作

| 分数 | 动作 |
|------|------|
| ≥ 85 | ✅ 直接分发 |
| 70-84 | 🔄 语言修正后分发 |
| < 70 | 🚫 人工复核 |

## 四、Escalation SOP

| 场景 | 触发条件 | 动作 |
|------|----------|------|
| 平台内容被下架 | 平台返回违规通知 | 记录原因 + 修正策略 + 人工审核 |
| 账号被封 | 连续多篇被下架 | 暂停该平台发布 + Founder 通知 |
| 本地化质量投诉 | 用户反馈用词不当 | 追溯修正 + 更新用词库 |
| 政策变化 | 台湾数位部/平台政策更新 | 快速评估影响 + 更新合规规则 |

## 六、与内容管道的集成

### 出海内容流

```
内容 Agent 简体产出
    ↓ relay/{content_id}_simplified.md
墨海出海（本 SOP）
    ↓ L1→L2→L3 本地化
Gatekeeper 本地化合规检查
    ↓ 通过
分发层 → Vocus / LINE / Facebook
```

集成要点：
1. Content Agent 产出后标记 `needs_localization: true`
2. 本地化版本写入 `relay/{content_id}_tw.md`
3. 本地化版本经过 Gatekeeper 合规检查（gatekeeper-sop 含平台规则）
4. 分发时原版（简体）和本地版（繁中）互不影响
