# 墨域私域 Agent SOP 技能包

## 适用 Agent
- 墨域私域 (crm.py)
- 集成：飞书群机器人（基建中）、企业微信 SCRM

---

## 一、核心原则

私域的本质不是「加微信然后卖东西」，而是**把信任做成资产**——用户留在你的企业微信里，是因为你持续提供超出预期的价值。

三条铁律：
1. **先给价值，再谈转化**：每 3 条价值内容配 1 条营销信息
2. **分层运营，拒绝群发**：不同价值的用户收到不同层级的内容
3. **数据驱动，拒绝拍脑门**：所有运营动作有数据闭环

## 二、Lead SOP（数据采集与用户洞察）

### 用户数据源

| 数据源 | 采集工具 | 频次 | 用途 |
|--------|---------|------|------|
| 企微客户数据 | SCRM API | 实时 | 用户画像/标签更新 |
| 社群行为数据 | SCRM 埋点 | 每日 | 活跃度/互动/退群率 |
| 订单/支付数据 | 电商系统 | 每日 | RFM 模型计算 |
| 飞书群互动 | 飞书 API | 每日 | 内容偏好/兴趣标签 |
| 客服对话 | 飞书消息记录 | 每周 | 用户痛点/常见问题 |

### RFM 用户分层模型

```
R (Recency) — 最近一次互动/消费距今天数
F (Frequency) — 近30天互动/消费次數
M (Monetary) — 累计消费金额

分层规则：
┌─────────────┬──────────────────────┬──────────┐
│ 层级         │ RFM 判定              │ 运营策略  │
├─────────────┼──────────────────────┼──────────┤
│ 🏆 超级用户  │ R<7 & F>10 & M>1000  │ VIP专属群 │
│ 💎 高价值    │ R<14 & F>5 & M>500   │ 福利群    │
│ 🌱 成长用户  │ R<30 & F>2           │ 培育群    │
│ 🆕 新用户    │ R<3 & F=1 & M=0      │ 欢迎群    │
│ 💤 流失预警  │ R>30 & F<2           │ 召回计划  │
│ ❄️ 已流失    │ R>90                 │ 不打扰    │
└─────────────┴──────────────────────┴──────────┘
```

### 流失预警自动触发

```
R > 30天 且 F < 2 → 自动标记「流失预警」
    ↓
自动推送专属优惠/1v1 关怀消息
    ↓
7 天无响应 → 标记「高流失风险」→ 转人工客服
    ↓
30 天无响应 → 标记「已流失」→ 停止推送，保留数据
```

## 三、Execution SOP（社群运营流水线）

### 标准社群运营流程

```
用户入群 → 欢迎触达 → 价值培育 → 活动激活 → 转化引导 → 留存维系
```

### Step 1: 企微基础架构

- **组织架构**：部门分组、员工账号层级、权限管理
- **客户联系配置**：欢迎语、自动标签、渠道活码、客户群管理
- **SCRM 工具集成**：
  - 微伴助手（基础功能）
  - 尘锋 SCRM（深度运营）
  - 微盛（企微+小程序）
  - 句子互动（社群自动化）
- **会话存档合规**：金融/教育等行业的监管合规要求
- **离职继承与在职转接**：确保人员变动不丢失客户资产

### Step 2: 社群分层搭建

| 群类型 | 用户层级 | 群规模 | 运营重点 | 消息频率 |
|--------|---------|--------|---------|---------|
| 欢迎群 | 新用户 | ≤200人 | 破冰+品牌认知+首单转化 | 每日 1-2 条 |
| 培育群 | 成长用户 | ≤200人 | 价值内容+互动活动 | 每日 2-3 条 |
| 福利群 | 高价值 | ≤150人 | 专属福利+限时活动 | 每日 1-2 条 |
| VIP 群 | 超级用户 | ≤50人 | 1v1服务+共创+内测 | 每日 1 条 |
| 快闪群 | 活动临时 | ≤500人 | 活动驱动+限时紧迫 | 活动期间高频 |

### Step 3: 社群 SOP 自动化

每个社群阶段的标准操作序列（可 SCRM 自动化）：

```
[欢迎语] → 自我介绍引导 → 价值内容 #1 → 
[间隔2h] → 互动话题 → 价值内容 #2 → 
[间隔4h] → 小活动/福利 → CTA 引导 →
[次日] → 价值内容 #3 → 转化邀约
```

每日运营节奏模板：
```
09:00  早安+今日话题（非营销）
12:00  午间轻内容（知识卡片/行业资讯）
15:00  互动活动（投票/打卡/抽奖）
18:00  价值干货（深度内容）
20:00  限时福利/活动预告（营销向）
22:00  晚安+明日预告
```

### Step 4: 用户生命周期管理

```
拉新 → 激活 → 留存 → 变现 → 传播
  │      │      │      │      │
  │      │      │      │      └─ 裂变激励/分销/口碑推荐
  │      │      │      └─ 阶梯定价/限时优惠/组合套餐
  │      │      └─ 签到/打卡/积分/等级体系
  │      └─ 首单优惠/新人任务/7日留存计划
  └─ 渠道活码/裂变海报/异业合作
```

每个阶段的关键动作：
| 阶段 | 目标 | 关键动作 | 衡量指标 |
|------|------|---------|---------|
| 拉新 | 获取企微好友 | 渠道活码、裂变海报、异业合作 | 添加率 |
| 激活 | 完成首次互动 | 欢迎语→破冰→首单优惠 | 7 日互动率 |
| 留存 | 持续活跃 | 签到、积分、内容价值 | 30 日留存率 |
| 变现 | 完成购买 | 限时活动、组合套餐 | 转化率、客单价 |
| 传播 | 用户推荐 | 裂变激励、分销、口碑 | 裂变系数 K |

### Step 5: 全漏斗转化优化

```
曝光 → 添加企微 → 入群 → 互动 → 浏览商品 → 下单 → 复购 → 推荐
 60%    40%       80%   50%      30%      15%    25%    10%
```

每个环节的优化策略：
- **曝光→添加**：优化渠道活码落地页、首次添加欢迎语
- **添加→入群**：明确入群价值（福利预告/专属内容）
- **入群→互动**：破冰活动、新人任务
- **互动→浏览**：内容种草、限时活动推送
- **浏览→下单**：限时优惠、社交证明、紧迫感
- **下单→复购**：会员体系、复购优惠、自动提醒
- **复购→推荐**：裂变激励、佣金分销

## 四、QA SOP（私域运营质量质检）

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 用户满意度 | 25% | 退群率、投诉率、NPS 评分 |
| 内容质量 | 25% | 价值内容占比 ≥75%、打开率 |
| 转化效率 | 20% | 漏斗转化率、ROI |
| 合规安全 | 15% | 无敏感词、无过度营销、合规存档 |
| 自动化健康 | 15% | SCRM 工具在线率、SOP 触发准确率 |

### 阈值动作

| 分数 | 动作 |
|------|------|
| ≥85 | 正常运行 |
| 70-84 | 优化低分维度 |
| 60-69 | L1 通知：调整运营策略 |
| <60 | 🚫 L2 审批：暂停自动化，人工接管 |

### 否决条件

- ❌ 单日退群率 > 5%
- ❌ 用户投诉涉及隐私泄露
- ❌ 营销内容占比 > 50%
- ❌ SCRM 工具连续 24h 离线

## 五、Escalation SOP

| 场景 | 触发条件 | 动作 |
|------|----------|------|
| 大规模退群 | 单群退群率 > 10% | L1 通知 → 暂停该群自动推送 → 分析原因 |
| 负面舆情 | 群内出现 3+ 用户负面反馈 | L1 通知 → 人工介入安抚 |
| SCRM 故障 | 工具离线 > 2h | L1 通知 → 切换备用方案 |
| 用户隐私风险 | 敏感信息泄露风险 | L2 审批 → 立即停止相关功能 |
| 转化率骤降 | 漏斗转化率连续 3 天下降 > 50% | L1 通知 → 运营策略复盘 |
