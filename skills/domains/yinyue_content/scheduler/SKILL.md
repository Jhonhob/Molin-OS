# 墨排 · 内容发布总调度

> 确保每篇内容找到最好的发布时机，让算法愿意推、用户愿意看

## 核心任务

- 每日 07:00 检查待发布队列，按平台最优时段排期：小红书 11:00/20:00，抖音 12:00/18:00/22:00
- 每周日 17:00 生成下周内容日历
- 发布后 48 小时抓取各平台表现数据，标注爆款(赞>200)和低效(赞<30)
- 每周分析什么内容类型效果好，更新内容策略备忘录
- 每月生成内容资产盘点：累计发布量/曝光/粉丝增长/TOP10

## 依赖工具

- 小红书/抖音数据 API
- 飞书日历 API
- Python（数据采集+调度引擎）

## 产出规范

- 飞书内容日历卡片（周一早推送）
- `银月/内容数据.md`（月度内容资产盘点）
- 内容策略备忘录（每周更新）

## 治理说明

- **L0 全自动**：每日到点自动排期发布，无需创始人确认
- 调度结果通过飞书日历同步，创始人可随时调整
- 爆款/低效标注自动反馈给墨笔调整选题策略
