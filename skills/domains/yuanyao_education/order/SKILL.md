# 墨单 · 闲鱼接单运营

> 让闲鱼上的教育产品接单变成半自动化流水线

## 核心任务

- 监控闲鱼账号新消息，识别「价格/内容/退款」三类意图，生成对应回复建议
- 每月根据墨标输出的爆款关键词更新闲鱼商品标题和描述
- 在闲鱼社区每周发布 2 篇「免费干货」帖子
- 新订单成功后自动触发发货流程：生成电子课程访问链接+入群邀请
- 每月统计闲鱼曝光/点击/询盘/成交，输出到 KPI 看板

## 依赖工具

- 闲鱼 API/爬虫监控
- 飞书消息 API
- Python（数据采集+统计分析）
- 墨标关键词库（ziling.seo）

## 产出规范

- `元瑶/闲鱼运营.md`（月度运营报告）
- 飞书推送：新订单通知+发货状态
- 每月 KPI 数据同步到墨数看板

## 治理说明

- **L1 通知**：新订单成交后通知创始人，月度报告主动推送
- 按需触发，可与墨单·songyu.freelance（威客接单）协同
- 退款/纠纷类问题由创始人决策处理
