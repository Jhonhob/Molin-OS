## 二、Execution SOP（私域运营流程）

### 用户生命周期管理

```
用户获取 → 欢迎/激活 → 日常互动 → 转化推进 → 留存/召回
```

### Step 1: 用户分层

按活跃度和价值分群：

| 分层 | 定义 | 运营策略 |
|------|------|----------|
| 🔴 核心用户 | 周互动 ≥ 3 次 或 已购买 | 专属内容 + VIP 权益 |
| 🟡 活跃用户 | 周互动 1-2 次 | 定期触达 + 价值内容 |
| 🟢 潜在用户 | 已关注但未互动 | 欢迎序列 + 教育内容 |
| ⚪ 沉默用户 | 30天未互动 | 召回策略 |
| ⚫ 流失用户 | 90天未互动 | 低强度召回或静默 |

### Step 2: 自动触达序列

#### 欢迎序列（用户关注后自动触发）
```
Day 0: 欢迎消息 + 价值承诺
Day 1: 免费资源/内容推荐
Day 3: 产品/服务介绍
Day 7: 互动引导 + 抽奖/活动
Day 14: 转化引导（试用/购买）
```

#### 定期互动
- **内容推送**：每日/每周精选内容（与 Content Agent 联动）
- **节日/热点**：即时热点互动
- **生日/纪念日**：自动生日祝福 + 优惠

#### 召回序列
```
沉默 7 天: 温馨提醒（"最近有什么新内容..."）
沉默 14 天: 价值推送（"你可能错过了..."）
沉默 30 天: 优惠/激励（"回来看看吧"）
沉默 90 天: 最终召回（"我们要清理好友了"）
```

### Step 3: 转化推进

```
识别购买意向信号
    ↓ 触发
个性化推荐
    ↓ 用户感兴趣
跳转到 Ecommerce Agent 完成交易
    ↓ 购买后
加入核心用户群
```

购买意向信号：
- 用户询问价格/功能
- 用户点击产品链接 ≥ 2 次
- 用户参与体验/试听活动

## 三、QA SOP

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 触达时机 | 25% | 是否在合适时间发送？ |
| 内容相关性 | 25% | 是否基于用户标签和偏好？ |
| 频率控制 | 20% | 是否超过每日/每周上限？ |
| 个性化程度 | 15% | 是否使用了用户信息？ |
| 合规性 | 15% | 是否有退订选项？隐私合规？ |

### 否决条件
- 同一用户日触达 > 3 次
- 未获同意的商业推广
- 隐私数据泄露

## 四、Escalation SOP

| 场景 | 触发 | 动作 |
|------|------|------|
| 用户投诉骚扰 | 用户反馈/举报 | 立即停止触达 + 人工审核 |
| 推送大面积失败 | 送达率 < 50% | 检查 LINE API + 降级 |
| 用户退订率激增 | 日退订 > 5% | 暂停推播 + 分析原因 |
| 互动率异常下降 | 连续 7 天下降 | 重新评估内容策略 |

## 六、集成设计

### 内容联动
```
Content Agent 产出适合私域分发的版本
    ↓ relay/private_domain_content_{date}.json
CRM Agent 按人群标签匹配内容
    ↓
LINE 推播/私信发送
```

### 客服联动
```
用户发起咨询
    ↓ LINE Messaging API
Service Agent 客服 SOP
    ↓ 处理完成后
更新用户画像 + 互动记录
```

### 电商联动
```
用户购买
    ↓ Ecommerce Agent
更新用户标签（已购买/客户等级）
    ↓
CRM Agent 调整分层和策略
```
