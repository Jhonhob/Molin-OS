## 简介 / Introduction

**墨麟OS** 是一套完整的 AI 一人公司操作系统。它不是工具集，也不是 Agent 框架——它是一个真正的、可运行的 AI 原生企业运营系统。

> 创始人只需在飞书上说一句需求，系统自动路由到对应子公司 Worker 执行，完成后回传结果。从内容创作到量化交易，从客户服务到竞争情报——全部自动完成。

Built on [Hermes Agent](https://github.com/nousresearch/hermes-agent) (Nous Research), Molin OS is a production-grade AI operating system for solo entrepreneurs who want to run an entire business with AI.

### 🔄 每日自动化飞轮
```
08:00 ── 情报银行   扫描+筛选   → relay/intelligence.json
09:20 ── 内容工厂   生成+SEO    → relay/content.json
10:45 ── 增长引擎   优化+分发   → 飞书/公众号/小红书
```
三棒全自动接力，断链级联告警。另有 16 项辅助 Cron 作业。

### 🧠 Obsidian Vault 记忆系统
四层记忆架构：
- **L1 工作记忆** — 飞书对话上下文（24h 清理）
- **L2 情节记忆** — Obsidian 结构化笔记
- **L3 语义记忆** — Obsidian `产出/` 永久存储
- **L4 程序记忆** — SKILL.md 技能文件（版本化管理）

### 🔍 MemPalace 语义检索 (NEW!)
全新 **MemPalace** 语义检索系统，在 Obsidian 知识库之上提供向量化语义搜索。支持：
- 多模态知识检索（笔记、代码、设计稿）
- 跨 vault 关联搜索
- 智能排序与上下文感知
- 与 Evolution Engine 深度融合，自动将知识卡片索引至 MemPalace

### 🚪 飞书网关集成
飞书对话作为主要交互入口。自然语言输入 → Handoff 自动路由 → 子公司执行 → 结果回传。也支持 CLI 终端和 REST API（:5050）接入。

### 🏛️ 5 级治理体系
L0 自动执行 → L4 绝对禁止，预算上限 + 审批门禁 + 审计追踪。

## 快速开始 / Quick Start

### 完整部署（推荐）

```bash
git clone git@github.com:moye-tech/Molin-OS.git
cd Molin-OS
bash setup.sh
```

`setup.sh` 自动完成：系统依赖检查 → Python 虚拟环境 → pip install Hermes Agent → 配置模板生成 → cron 注册 → vault 镜像初始化。

### 仅部署脚本

```bash
git clone git@github.com:moye-tech/Molin-OS.git
cd Molin-OS
bash scripts/deploy.sh
```

### 配置 API Keys

编辑 `~/.hermes/.env` 填入 API Keys：

```bash
DEEPSEEK_API_KEY=sk-xxx
DASHSCOPE_API_KEY=sk-xxx
OPENROUTER_API_KEY=sk-xxx
```

### 知识库同步

如果已有本地 Obsidian vault，运行：

```bash
python3 scripts/vault_git_sync.py
```

> **注意**: 从本 Mac 推送至 GitHub 请使用 SSH 方式（HTTPS 因 TLS 握手超时会失败）。

### 验证安装

```bash
python -m molib health
```

## 治理模型 / Governance Model

5 级审批体系，基于预算上限 + 风险等级的量化治理。

| 级别 | 名称 | 预算上限 | 规则 |
|:-----|:-----|:---------|:-----|
| L0 | 自动执行 | ¥0 | 零成本操作，AI 自动完成无需审批 |
| L1 | AI 自审 | ≤ ¥10 | AI 内部检查后自动执行 |
| L2 | 人工确认 | ≤ ¥100 | 需创始人确认后执行 |
| L3 | 董事会审批 | ≤ ¥1,000 | 重大决策需全面评估 |
| L4 | 绝对禁止 | — | 涉及真实现金/转账/支付/改价，绝不触碰 |

核心原则：
- 月度运营预算 ¥1,360，80% 时触发预警
- 审计日志 90 天保留
- Token 30 天轮换，禁止提交凭证
