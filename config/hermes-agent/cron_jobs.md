## 部署状态

所有作业由 Hermes Agent cron 工具管理，通过 `config/domains/*.yaml` 中的 flywheel 配置驱动。

启用命令：
```bash
hermes cron list                    # 查看所有作业状态
hermes cron resume <job_id>         # 恢复单个作业
hermes cron run <job_id>            # 手动触发一次验证
```
